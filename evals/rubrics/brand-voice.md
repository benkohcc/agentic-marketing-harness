# Rubric — brand_voice (1–5)

Used by the brand-reviewer. Anchored on `MARKETING.md` body "Voice, with examples" and
`brand.examples_ref`. Score each asset file; findings quote the text.

| Score | Meaning | Tell-tales |
|---|---|---|
| 5 | Indistinguishable from the "This" examples | Specific product detail in the first sentence; CTA names an object; no adjective without a noun to earn it |
| 4 | On-voice with one soft spot | One generic phrase; a paragraph without a concrete detail; CTA slightly vague |
| 3 | Competent, could be any brand | Correct register, no `never_say`, but no specificity; reads as template |
| 2 | Off-voice | `avoid` patterns dominate: superlatives, jargon, manufactured urgency; wrong register |
| 1 | The brand's opposite | Resembles a "Not this" example; would embarrass the team if sent |

Rules of scoring:
- Score the worst paragraph, not the average. One bad opener sinks an email.
- `never_say` hits are not scored here — copy-lint blocked them. If one slipped through,
  that is a bug report, not a 1.
- Do not reward length. Short and specific beats long and warm.
- Compare against the examples file every time. Memory of "what the brand sounds like"
  drifts; the file does not.
