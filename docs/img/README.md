# docs/img

Illustrations for the main README. Each figure exists as vector source (`.svg`) and as a
2× PNG screenshot rendered from it with headless Chromium. Regenerate both with the
figure script when the harness changes; the PNGs are what the README embeds so they
render identically on GitHub in light and dark mode.

| `isolation` | Who does each step: the sub-agents |

| `fixtures` | The honest gap → audience rules and journey simulation |
